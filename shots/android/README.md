# Android website screenshots

Match, Multi-Match and AastroAI light/dark assets were captured from the exact signed Android 1.0.10 (198), source `62d1105`, on the dedicated Android 14 ARM64 QA emulator on 18 September 2026. They show synthetic QA profiles. The pixels were only resized and encoded to WebP; no UI content was fabricated. Light and dark captures use the app's Yellow theme.

`match-*` shows Rohan/Priya's computed Match result, `multi-match-*` compares Ananya with Rohan and Priya, and `aastroai-*` shows all three selected in the same conversation with context-aware questions. The regression/report for this build is at https://www.aastroastra.com/release/reports/android-v1.0.10-0044381324/.

Other feature screenshots predate this capture. No original user reference photos or authentication screenshots are published here.
