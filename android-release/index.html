Play Console limits enforced at build time: app name 30, short description 80, full description 4000, release notes 500 characters; feature graphic 1024 × 500, phone screenshots 1080 × 1920, all 24-bit PNG without alpha. Odia ships in the kit for the website and press, but Google Play has no Odia listing language yet. Every set uses the five website themes, with colours read from the site stylesheet at build time and no gradient fills. ZIPs are hosted on the GitHub Release for this version; the page keeps small previews and the PNG originals.
