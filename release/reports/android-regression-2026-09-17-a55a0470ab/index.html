High · Open

Face reading fails on every photo, and shows the raw Java error

On the release build, picking any photo ends with "Attempt to invoke virtual method 'java.lang.Class java.lang.Object.getClass()' on a null object reference" on screen. Reproduced with two different images, including a real photograph, so it is not about the picture. The face model and its library are inside the APK. Two things to fix: whatever returns null in the measuring step, and the screen, which prints an exception message instead of a sentence a person can act on.

FaceLandmarkDetector.geometry via FaceReadingViewModel.analyze, which falls back to e.message for anything that is not a DetectionError

High · Fixed and verified in this run

Chat and Explain broke on any answer citing a source without a verse

The server sends "verse": null for chapter-only sources, the app declared it as a non-null string, and the chat decoder did not coerce nulls. Chat silently fell back to the offline answer ("I couldn't reach the server") and Explain printed the serialization error. One shared, null-tolerant decoder now serves buffered, streamed and explain replies. After the fix, chat answered in 14.4 s and Explain in 19.3 s.

ChatWireJson in ChatWireModels.kt, commit e47920a, with two regression tests

Medium · Open

The onboarding Mini Kundali says "Chart not ready yet" even with a birth place

Mumbai was searched, picked and saved, and the same chart draws correctly on the Kundali page a minute later. The onboarding screen fetches the real chart once, in a LaunchedEffect when it opens, and shows the placeholder for the rest of the session if that one attempt does not finish. The screen needs a retry, or to wait for the fetch it started.

MiniKundaliScreen.kt:125 calls loadAccuratePlanets(); it returns early and never runs again

Medium · Fixed in this run

Match verdict lines were English-only, in every language

The three numerology vibe verdicts under the match percentage were hardcoded English inside MatchNumerology, so Hindi, Marathi, Gujarati and Tamil users read them in English. They now carry all five languages, and the em dashes in them are gone (workspace rule).

How this was run

  • The release APK was driven through adb and uiautomator (scripts/regression/run_android_regression.py), starting from cleared app data and signing in with the store-review test number.
  • "Time on screen" runs from the tap until the expected content is visible, so it includes network, parsing and drawing.
  • Backend calls were replayed as the app sends them (scripts/regression/endpoint_latency.py) with a QA test number; chart calls hit the server cache after the first run.
  • The palm and face photos are Wikimedia Commons images (CC BY-SA); see the fixture SOURCES.md for attribution.
