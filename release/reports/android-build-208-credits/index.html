What changed

  • The Amplitude flag digital-credits-enabled controls the Android credit experience.
  • Credit mode shows the wallet capsule in AstroAI and section assistants, and hides the daily 100/100 badge.
  • The shared Settings and chat wallet uses a responsive refill grid: 100 / ₹100, 500 / ₹500, 1,000 / ₹1,000. Purchase actions remain disabled.
  • Off mode hides credit UI, skips new credit balance/quote/reservation calls and restores existing subscription rules. Already reserved operations remain recoverable.

How it gets enabled

Create the named flag with on and off variants in the Amplitude Experiment Android client deployment. Provide the client deployment key to the Android build, then install that configured build. Flags refresh on foreground and authentication changes.

Build 208 has no deployment key configured. It defaults to credit mode; remote switching requires a new configured build. The flag does not enable paid checkout or change server billing policy.
