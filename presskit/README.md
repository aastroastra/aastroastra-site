## Quick Brand Reference

**Primary accent**: Gold `#E0A015`
**Signature gradient**: `#FACC15` → `#FB923C` → `#EAB308`
**Themes**: Yellow · Light (default), B&W · Light, Yellow · Dark, B&W · Dark
**Fonts**: Noto Serif (display), Inter (body)
**Tagline**: *One who believes.*

## Logo Usage

- **Light backgrounds**: use the gold mark / full logo as-is.
- **Dark backgrounds**: render the mark white; the gold gradient is fine on colour.
- Maintain clear space equal to one "A" height; never stretch, rotate, or add shadows.
